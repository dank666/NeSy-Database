# NeSy-Database

Data for the survey "Neuro-Symbolic Agentic AI: A Survey on Planning, Memory, and Verification" by Tejing Wang and Fei Hao, submitted to ACM Computing Surveys. Section 2 of the article describes the four search stages and the eligibility criteria.

| Path | Content |
|---|---|
| `classification_202.csv` | Codes of the 202 works in the corpus (online Appendix A of the article) |
| `stage4_sample_classification.csv` | Codes of the 103 works in the stage-4 sample, which lies outside the corpus |
| `coding-rules.md` | Coding manual (online Appendix B); its first table defines the coding fields |
| `stage1/screened_120.csv` | Stage 1 (exploration): the 120 eligible works |
| `stage1/three communities paper list/sources.md` | Stage 1: the three community paper lists that were consulted |
| `stage2/records/` | Stage 2 (targeted arXiv searches): the 60 records returned |
| `stage2/screened_9.csv` | Stage 2: the 9 eligible works added |
| `stage3/records/` | Stage 3 (validation search): results of the fixed query on arXiv, the ACM Digital Library, IEEE Xplore, and SpringerLink |
| `stage3/screened_36.csv` | Stage 3: the 36 eligible works added |
| `stage4/records/` | Stage 4 (wide arXiv search): the records returned and their screening status |
| `stage4/screened_37.csv` | Stage 4: the 37 eligible works added from the 108 most-cited records |
